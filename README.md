# CTRL Informática

Landing page estática em HTML, CSS e JavaScript, preparada para GitHub Pages. Sem backend, instalação, compilação ou dependências de execução.

## Visualizar

Abra `index.html` no navegador. Para testar por HTTP, use um servidor estático local de sua preferência na pasta do projeto.

## Publicar no GitHub Pages

1. Crie ou utilize um repositório na organização `ctrlinformatica`.
2. Envie o conteúdo desta pasta para a raiz do repositório, mantendo `index.html`, `styles.css`, `script.js`, `.nojekyll` e a pasta `assets`.
3. Nas configurações do repositório, abra **Pages**. Selecione a publicação por branch (**Deploy from a branch**), a branch que contém os arquivos e a pasta **/ (root)**.
4. Salve e aguarde o GitHub informar o endereço publicado.

Os caminhos dos arquivos são relativos: funcionam tanto no domínio da organização quanto em uma subpasta de projeto. Não é preciso editar caminhos para publicar.

O projeto foi preparado localmente; nenhum repositório foi criado e nenhuma publicação foi realizada.

## SEO e acessibilidade

Inclui idioma pt-BR, título e descrição, Open Graph textual, favicon, estrutura semântica, link para pular ao conteúdo, foco visível, controles de menu acessíveis, rótulos de links, navegação por teclado e preferência por movimento reduzido. Nenhum domínio canônico foi inventado. Após a publicação, é possível acrescentar a URL definitiva como `canonical` e `og:url`; nenhuma imagem social foi criada.
